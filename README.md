# 📝 Task Flow - Full Stack To-Do App

A full-stack MERN (MongoDB, Express, React, Node.js) application that allows users to manage their daily tasks. This project is fully deployed and connected to a cloud database.

## 🚀 Live Demo
**Check out the live app here:** [https://task-flow-client-ten.vercel.app](https://task-flow-client-ten.vercel.app)

## ✨ Features
* **Create Tasks:** Add new tasks to your list instantly.
* **Real-time Database:** Data is stored in MongoDB Atlas and persists even after refreshing.
* **Cloud Hosted:** Frontend and Backend are hosted on Vercel for fast performance.

## 🛠️ Tech Stack
* **Frontend:** React.js, Vite, Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas
* **Deployment:** Vercel

## 📂 Project Structure
* `/client`: The React frontend application.
* `/server`: The Node.js Express API.

## ⚙️ How to Run Locally
1. Clone the repository: `git clone https://github.com/SivaSajee/task-flow.git`
2. Install dependencies for both client and server:
   * `cd client && npm install`
   * `cd server && npm install`
3. Start the project:
   * Client: `npm run dev`
   * Server: `node index.js`
